# HOLYDON BUILDER

A free-first website generator MVP. The current build is template-driven: it interprets a plain-language prompt into a starter website, then lets users edit the brand name, headline, tagline, light/dark mode, and accent color. Preview and HTML export are client-side and require no API key.

## Run locally
- `npm install`
- `npm run dev`

## Current scope
- Prompt entry and six starting templates
- Responsive preview with desktop/mobile frame
- Basic editable content and theme controls
- HTML code view and downloadable standalone HTML
- No paid API, database, or auth required

AI provider integration, richer component editing, project saving, and one-click publishing are planned follow-up milestones.
